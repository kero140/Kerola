# KEROLA — Creative Memory Journey

نسخة مستقلة من الموقع، بتصميم تحريري/سينمائي وردي هادئ، متجاوب للموبايل، ومعرض تفاعلي لكل الذكريات المتاحة في المشروع.

## المحتوى
- 24 ذكرى فريدة: كل الصور والفيديوهات الموجودة في قائمة المشروع مستخدمة في المعرض.
- الفيديوهات تُعرض بعناصر تشغيل فعلية داخل نافذة الذكرى، مع إيقاف الفيديو عند الانتقال لذكرى أخرى.
- تنقّل بالسابق/التالي، لوحة المفاتيح، والسحب على شاشة الموبايل.
- فلترة حسب الصور أو الفيديوهات، وكلمة دخول `kerola` والباب السري `rolaa`.
- لا توجد مكتبات JavaScript خارجية مطلوبة. الخطوط الخارجية اختيارية، ويظل الموقع يعمل بدونها.

## النشر
ارفع محتويات مجلد `KEROLA-FRESH` إلى مجلد مستقل في GitHub Pages. لا تستبدل موقعك القديم قبل ما تراجع النسخة الجديدة.

## تنبيه مهم بخصوص الموسيقى
الأرشيف الذي بُنيت منه هذه النسخة لا يحتوي ملفات MP3 فعلية داخل `assets/audio`؛ لذلك لم أضع أسماء ملفات وهمية أو أدّعي أن التشغيل المحلي اتصلح. قائمة الأغاني موجودة، وتفتح نتائج الاستماع. لإعادة تشغيل الأغاني محليًا يلزم نقل ملفات MP3 الخمسة الموجودة في نسختك القديمة إلى `assets/audio` وربط كل اسم بالملف الفعلي، من غير حذف أي ملف أصلي.
